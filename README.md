# Tran Minh Chi — Portfolio

A lightweight, responsive portfolio for a Management Information Systems student open to entry-level opportunities across business analysis, business operations, and information systems support. It uses plain HTML, CSS, and JavaScript and has no external runtime dependencies or web-font requests.

The home page uses a locally stored portrait at `assets/avatar.jpeg`. Subtle scroll reveals respect the visitor's reduced-motion preference.

## Site contents

- Profile, academic background, and areas of focus
- A clearly labeled, self-initiated accounts payable process and sample-data case study in `projects/ap-invoice-review/`
- Academic accounts payable application project, described as a student contribution
- Work experience, certifications, and language skills
- Email and GitHub contact links

The AP case study is a learning exercise based on an explicitly fictional scenario and synthetic invoice dataset. Its process, requirements, figures, and limitations are documented in the project folder; it is not client work or real financial evidence.

Update the page content and contact details in `index.html`, styles in `styles.css`, and mobile navigation behavior in `script.js`.

## Publish with GitHub Pages

In the repository settings, open **Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`. GitHub Pages displays the published URL in the Pages settings.
